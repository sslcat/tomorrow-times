These are new authorial proposals, **not established canon**. Each uses a dated event, existing participants, an existing published cause, structured facts and no FTL or travel effects. Each has a draft template with exact claim references and distinct follow-through. The event validator checks the proposals. The local staging command backs up the database, inserts only `proposed` events and `Proposed` storylines, writes audits, and does not create public articles, threads or effects. It is idempotent.

Run `npm run newsroom:stage-v2` locally. In the existing authenticated development editorial desk, inspect a proposal, approve its event after continuity review, create its draft, edit/review the prose, approve that draft, and intentionally publish when due. Draft templates deliberately use conditional analysis in places; the final editor must make the text match the approved announcement. No approval is inferred from staging. Once its first event is published, its storyline becomes publicly discoverable with the published facts. Before that, search, sitemap, profiles and direct public storyline URLs exclude it. Existing generation controls and production auth restrictions are unchanged.

## Quality gate

Review immediate who/did-what clarity, one specific curiosity, source support for every factual claim, attributed uncertainty, natural language, readable 1–3 minute pacing, distinct voice and a next consequence. An exact structured claim check is not a semantic verifier. Reject false arrests, split claims, discoveries of life or simultaneous interplanetary performances. Check the whole body against the headline; do not promise details absent from the report.

`docs/V2_HEADLINE_REVIEW.md` records all 40 before/after headlines and source events. V2 projection applies only to exact original documents, preserves original text in the database, exposes it on the article, and yields to any later correction or retraction. Search accepts the original headline as well as current presentation. Official forum headings follow the article; reader-authored topics remain untouched. The first five homepage article slots are the five supported music-industry stories, followed by four crime/case reports and eleven wider-world pieces. This prioritizes celebrity coverage above/near the fold without repeating the same event as multiple invented scandals. Wider entertainment formats await approval of new events.
